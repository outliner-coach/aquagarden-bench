# AquaGarden — claude-opus-5-5

브라우저 하나로 실행되는 3D 네이처 아쿠아리움입니다. `index.html` 파일 하나로 되어 있습니다(1,422줄, 76,803바이트).

## 제작 방식

- 참고한 자료는 `assets/reference.jpg`와 원프롬프트(`prompt.md`)뿐입니다. 다른 버전이나 git 이력은 보지 않았습니다.
- three.js **0.170.0**은 jsDelivr에서 importmap으로 불러오고, OrbitControls 애드온도 함께 씁니다. 외부 텍스처·모델·이미지·fetch는 쓰지 않으며, 모든 형상과 색은 코드로 만듭니다.
- 모델: Claude Opus 5.5 (`claude-opus-5-5`)

## 실제 수행한 검증

`python3 -m http.server 8791`을 띄우고 Playwright MCP(Chromium, 1440×860)로 확인했습니다. 작업이 끝난 뒤 서버는 종료했습니다.

- **콘솔**: 처음 로드했을 때 `favicon.ico` 404 에러가 1건 있어서 `<link rel="icon" href="data:,">`를 추가했습니다. 수정 후 다시 로드했을 때 에러와 경고는 0건이었습니다.
- **물고기**: `window.__aqua.fishes`에서 종별 수를 확인했습니다(neon 18, harlequin 10, platy 6, betta 1, cory 4, 총 39). 약 2초 동안 39마리가 모두 이동했습니다(최소 0.16, 최대 2.3 단위).
- **클릭 명언**: 화면을 격자로 레이캐스트해 15개 분류가 모두 클릭 대상으로 잡히는 것을 확인했습니다. 실제 마우스 클릭으로 바위, 유목, 바닥재, 베타의 명언 카드가 표시되는 것도 확인했습니다.
- **조명 UI**: '석양' 프리셋을 누르면 state가 밝기 0.62, 3100K, 48°로 바뀌고 슬라이더 표시값도 함께 바뀌었습니다. 스크린샷에서도 따뜻한 색조가 확인됩니다. 밝기 슬라이더에 값을 입력하면 `state.bright`가 0.3으로 바뀌었습니다.
- **성능**: 테스트 환경에서 requestAnimationFrame이 약 120fps로 측정됐습니다. 하드웨어에 따라 달라집니다.

## 참고 이미지 대비 보정 내역

1. 첫 스크린샷에서 모스 덩어리가 큰 원판처럼 보였습니다. 크기를 0.05–0.12에서 0.028–0.07로 줄이고, 개수는 최대 3,200개에서 7,000개로 늘렸으며, 색을 어둡게 하고 위치를 흩뜨렸습니다.
2. 골든 플래티가 지나치게 크고 둥글어서 길이 0.42→0.34, 체고 비율 0.42→0.34로 줄였습니다.
3. 뒤쪽 수초가 참고 이미지보다 성기어서 왼쪽 42→70, 가운데 60→95, 붉은 로탈라 62→90 줄기로 늘리고 잎을 키웠습니다.
4. 전경 카펫이 너무 길어서 높이를 0.12–0.3에서 0.08–0.2로 낮추고 개수를 15,000에서 18,000으로 늘렸습니다.
5. 수조 윗부분이 잘려서 카메라를 뒤로 물리고 높였습니다((0.4,3.1,11.2)→(0.3,3.4,12.6)).
6. 밝은 백스크린 앞에서 기포가 보이지 않았습니다. 기포 테두리를 어둡게 굴절된 색으로 바꾸고, 에어스톤을 왼쪽 뒤 구석에서 가운데 뒤로 옮겨 기포 줄기가 보이게 했습니다(석양 스크린샷에서 확인).
7. 근접하면 모스가 각져 보여서 지오메트리를 Icosahedron detail 0에서 1로 바꿨습니다.

검증용 스크린샷은 Playwright 허용 경로인 `.playwright-mcp/opus55-*.png`에 저장했습니다(이 폴더 밖이며, 결과물에는 포함되지 않습니다).

## 알려진 한계

- 그림자용 depth 재질에는 흔들림과 꼬리 웨이브가 들어가 있지 않아서, 물고기와 수초의 그림자는 정지된 형태로 계산됩니다. 수초는 그림자를 드리우지 않습니다.
- 물고기 레이캐스트는 셰이더로 변형하기 전의 정적 지오메트리를 기준으로 합니다. 지느러미 끝처럼 움직임이 큰 부분은 클릭 판정이 약간 어긋날 수 있습니다.
- 물고기는 유목 가지 일부와 수초는 통과할 수 있습니다. 장애물은 바위 타원체와 굵은 가지 위주의 근사치입니다.
- 코스틱 무늬는 그림자 영역에서도 꺼지지 않습니다.
- 명언 출처 가운데 '~의 말로 전해짐'이나 '작자 미상'으로 표기한 것은 출처가 분명하지 않은 인용입니다.
- 첫 로드에는 CDN 접속이 필요합니다(three.js).
- 모바일 레이아웃은 CSS로 대응했지만 실제 모바일 기기에서는 검증하지 않았습니다.
