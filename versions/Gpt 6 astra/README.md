사진을 배경으로 붙이거나 다른 버전의 구현 코드를 재사용하지 않았습니다.

## 제작 조건

사용자의 한 번의 제작 요청에서 원문과 이미지를 읽고 구현, 브라우저 검증, 필요한 보정, 갤러리 통합, 배포를 진행했습니다.
따라서 **원 프롬프트를 입력으로 사용한 에이전트 제작 결과**이며, 무수정 단일 응답 또는 엄밀한 one-shot 측정으로 표기하지 않습니다.
화면 검증에는 Aside Browser와 Playwright CLI를 사용했습니다. 코드는 GPT-6 Astra가 작성했으며, 브라우저 QA 도구는 코드 수정에 사용하지 않았습니다.

## 구현

- 외부 빌드 없이 HTML 하나로 실행합니다. 실행 시 three.js `0.170.0`을 jsDelivr에서 불러옵니다.
- 베타 1, 네온테트라 12, 엠버테트라 6, 허니구라미 2, 코리도라스 3: 총 5종 24마리.
- 각 종의 몸통 비율, 색, 지느러미, 유영 높이와 속도가 다릅니다. 두 테트라 종은 이웃의 결속·정렬·분리를 계산합니다.
- 유목은 끝으로 갈수록 가늘어지는 곡선 튜브, 바위는 변형된 다면체와 절차적 층리·이끼 재질입니다.
- 수초 잎은 인스턴싱과 버텍스 셰이더로 흔들립니다. 기포는 서로 다른 속도로 상승하고, 꼬리 관절과 지느러미 면·살이 움직입니다.
- 바닥·바위·유목 표면에 움직이는 코스틱 패턴을 적용합니다. 실제 광학 시뮬레이션은 아닙니다.
- 오후·노을·달빛 프리셋, 밝기와 색온도 슬라이더, 일시정지·재개, 카메라 회전·확대·초기화, 전체 화면.
- 물고기·유목·바위·수초의 실제 3D 레이캐스트 선택과 키보드용 대상 선택 메뉴.
- 명언 기능은 오브젝트에 맞춘 9개의 창작 문장입니다. 작가에게 잘못 귀속하지 않도록 `AquaGarden · 창작 문장`으로 표시합니다.
- `prefers-reduced-motion` 사용자는 정지 상태로 시작하며, 재개 버튼으로 유영을 켤 수 있습니다.
- 로딩 실패와 WebGL 컨텍스트 손실 안내, 보이지 않는 탭의 렌더링 절약.

## 조작

드래그로 회전, 휠로 확대·축소, 오브젝트 클릭으로 문장 보기.
캔버스에 키보드 초점을 두면 방향키로 회전, `+` / `-`로 확대·축소, `0`으로 초기화합니다.
`F`는 전체 화면, `Escape`는 열린 패널과 문장을 닫습니다.

## 로컬 실행

저장소 루트에서 `python3 -m http.server 8791` 실행 후 아래 주소를 엽니다.

http://localhost:8791/versions/Gpt%206%20astra/index.html

읽기 전용 브라우저 진단: `window.aquarium.inspect()`, `window.aquarium.projectObjects()`.
월드 좌표는 x가 오른쪽, y가 위쪽, z가 정면입니다.

## 검증 기록

2026-09-05, Chromium 실제 렌더링 기준:

- 데스크톱 1440×900 및 모바일 크기 390×844에서 화면을 캡처하고 직접 확인했습니다.
- 5종 24마리, 100개 기포, 모든 셰이더 프로그램 정상 동작을 확인했습니다. 초기화부터 상호작용 후까지 콘솔 오류·경고가 없었습니다.
- 물고기 위치·꼬리와 시간이 변하며, 일시정지 동안 같은 값이 유지되고 재개하면 다시 변합니다.
- 세 조명 프리셋, 밝기 10~120%, 색온도 조작이 화면과 상태에 반영됩니다.
- 베타·바위·유목을 실제 포인터로 클릭해 각 대상의 문장을 확인했습니다. 선택 메뉴의 녹색·붉은 수초 문장도 확인했습니다.
- 모바일 조명·문장 패널의 경계가 화면 안에 들어오고, 두 패널이 겹치지 않습니다. 가로 넘침이 없습니다.
- 카메라 드래그·휠 확대·초기화, 모션 줄이기 설정에서의 정지 시작·사용자 재개를 확인했습니다.
- 검증 중 배경의 수평 경계, 수초 줄기 연결, 모바일 시점 거리로 인한 과도한 안개, 진단용 유목 좌표를 보정했습니다.
- 이 검증은 데스크톱 Chromium의 모바일 크기 에뮬레이션입니다. 실제 iOS/Android 기기 검증은 포함하지 않습니다.
