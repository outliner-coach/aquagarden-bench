# GPT-5.6 Sol xhigh · AquaGarden Bench

`GPT-5.6 Sol`을 `xhigh` 추론 강도로 실행해 공통 원프롬프트와 `assets/reference.jpg`만 보고 새로 만든 독립형 3D 수족관입니다. 다른 벤치 버전의 구현 코드는 참조하지 않았습니다.

## 실행

정적 HTTP 서버에서 `index.html`을 엽니다. 런타임 의존성은 버전을 고정한 Three.js ES module CDN 하나뿐입니다.

## 구성

- Three.js `0.180.0`
- 물고기 4종, 총 40마리: 카디널테트라 14, 러미노즈테트라 10, 엔젤피시 4, 엠버테트라 12
- 같은 종끼리의 응집·정렬·분리와 경계 회피를 결합한 군영 유영
- 꼬리·등지느러미·양쪽 가슴지느러미 애니메이션
- 118장의 분절 수초 잎을 CPU로 변형해 만드는 물결 흔들림
- 62개 기포, 절차적 암석, Catmull-Rom 유목, 셰이더 수중 광선
- 조명 슬라이더, 오브젝트별 명언, 드래그 시점, 휠 확대
- 일시정지, 초기화, 전체화면과 키보드 단축키
- `window.render_game_to_text()`, 결정론적 `window.advanceTime(ms)` 테스트 훅

## 키보드

- `Space` 또는 `P`: 일시정지/재생
- `R`: 초기화
- `Q`: 오브젝트 범주별 명언 순환
- `F`: 전체화면 전환
- `Esc`: 명언 닫기 또는 전체화면 종료

벤치 통합 전 검증 내역은 [`progress.md`](./progress.md)에 기록합니다.
