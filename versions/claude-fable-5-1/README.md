# AquaGarden 3D · 디지털 수족관

브라우저에서만 돌아가는 3D 네이처 수조입니다. 빌드 과정도, npm도 없습니다.
`index.html` 파일 **하나**가 전부이며, 모든 텍스처와 형상은 코드로 생성됩니다
(외부 이미지 없음, `fetch` 없음).

---

## 실행 방법

### 1) 그냥 더블클릭
`index.html` 을 더블클릭하면 기본 브라우저에서 바로 열립니다 (`file://`).
Three.js 는 jsdelivr CDN 에서 불러오므로 **인터넷 연결이 필요**합니다.

### 2) 로컬 서버로 열기 (권장)
```bash
cd "aquagarden_claude_fable 5.1"
python3 -m http.server 8765
```
브라우저에서 <http://localhost:8765/index.html> 접속.

> 서버를 쓰면 캐시·보안 정책 문제가 없어 가장 안정적입니다.

## 조작법

| 동작 | 방법 |
|---|---|
| 시점 회전 | 마우스 드래그 / 한 손가락 드래그 |
| 확대·축소 | 휠 스크롤 / 두 손가락 핀치 |
| 명언 보기 | 오브젝트 클릭 (탭) |
| 명언 닫기 | 명언 카드 클릭, 빈 곳 클릭, 또는 6초 대기 |
| 조명 패널 접기 | 패널 우측 상단 `−` / `+` |

시점은 수조 정면 기준 **좌우 ±60°**, 위아래 제한, 줌 거리 제한이 걸려 있어
수조 안으로 들어가거나 뒤로 넘어가지 않습니다.

### 조명 패널 (우측)
- **밝기** 0 ~ 200 %
- **색온도** 2700K(따뜻함) ↔ 9000K(차가움)
- **물 색조** 푸른빛 ↔ 초록빛
- **프리셋** `주광`(기본) · `석양` · `달빛` · `RGB`(색상 순환)
- **토글** `광선`(물속 빛기둥) · `그림자`

프리셋을 누르면 슬라이더가 함께 움직이고, 조명은 약 0.8초에 걸쳐 부드럽게 전환됩니다.

## 담긴 것들

### 하드스케이프
- **유목** — `CatmullRomCurve3` + `TubeGeometry` 로 만든 굵기 변화(테이퍼) 가지 15 개:
  굵은 본줄기 → 3 개의 큰 가지 → 잔가지, 뿌리 2 개, 부러진 그루터기 3 개.
  나뭇결 노이즈를 가지 축 방향으로 늘려 세로 결이 보이도록 처리
- **바위** — 정이십면체(detail 4) 10 개를 `mergeVertices` 후 3 단 노이즈로 변형:
  큰 형태 + 이방성 지층 결 + 미세 입자, 균열 밴드는 안쪽으로 파고 정점 컬러로 어둡게.
  부드러운 노멀(면 각짐 없음), 따뜻한 회베이지. 주변에 자갈 10 개 (2 개는 카펫에 반쯤 묻힘)
- **바닥재** — 뒤로 갈수록 높아지는 경사 + 마운드, 캔버스 생성 흙 텍스처

### 수초 (전부 정점 셰이더로 흔들림 · 밑동 고정, 끝이 가장 많이 움직임)
- **헤어그라스 카펫** — `InstancedMesh` 11,000 포기. 균일 격자가 아니라 **포기(tuft) 중심 + 지터**
  방식으로 심어 사이사이 흙이 드러나고, 앞쪽은 짧고 성글게 · 중경은 길고 촘촘하게.
  잎은 얇고 살짝 휘며, 정점 컬러로 밑동이 어두워져 깊이감이 생김.
  색은 연두(#9ccd3a)~진초록(#4f8f2a) 사이에서 개체마다 다르게, 채도는 약간 낮춤
- **초록 유경수초** — 좌측·후경 9 무더기. 줄기마다 4~6 장의 좁은 타원 잎이 윤생하고
  위로 30~45° 들려 있으며, 마디마다 요(yaw)가 랜덤이라 원뿔이 아니라 잎 덩어리로 보임
- **붉은 유경수초** — 우측 5 무더기. 작은 타원 잎이 촘촘하고,
  밑동 초록 → 주황 → 붉은색 → 마젠타로 이어지는 4 단 그라디언트 (로타라/루드위지아 느낌)
- **발리스네리아** — 후경 좌우 5 무더기, 리본형 잎이 가장 크게 흔들림
- **이끼** — `InstancedMesh` 778 덩이. 가지마다 고르게 뿌리지 않고 **13 개 앵커**
  (가지 분기점·굵은 가지 윗면·줄기 밑동·부러진 그루터기)에 15~40 개씩 겹쳐 심어
  하나의 폭신한 쿠션으로 보이게 했고, 그 사이에는 맨 나무가 길게 드러남.
  바위는 위쪽 4 개에만 얹음. 색은 밝은 연두가 아니라 약간 푸른 중간~진초록

### 물고기 (5종 20마리, 전부 절차적 생성 — 모델 파일 없음)
| 종 | 수 | 특징 |
|---|---|---|
| 붉은 베타 | 1 | 큰 베일테일·등지느러미·뒷지느러미, 느리고 우아하게 우측 상단을 배회, 가끔 멈춤 |
| 노란 물고기 (플래티/구피) | 4 | 통통하고 밝은 노랑–주황, 중층 |
| 네온테트라 | 10 | 파란 형광 줄무늬 + 붉은 하복부, 보이드(응집·분리·정렬) 군영 |
| 코리도라스 | 3 | 바닥을 훑고 다니는 저층어 |
| 구피 | 2 | 주황 부채꼬리 |

몸통은 길이 방향으로 옆으로 물결치고(꼬리로 갈수록 진폭 증가), 꼬리지느러미는
위상 지연을 두고 더 크게 흔들리며, 가슴지느러미는 따로 퍼덕입니다.
**헤엄 속도가 빨라지면 꼬리 박자도 빨라집니다.** 벽·수면·바닥·하드스케이프
(보이지 않는 구체로 근사)를 피하고, 종마다 선호 수심이 다릅니다.

### 물 · 빛
- `FogExp2` 로 은은한 청록 수중 감쇠
- 정점 파동 + 해석적 노멀로 일렁이는 수면. **프레넬 알파**라 정면에서는 거의 투명하고
  스치는 각도에서만 옅게 비침. 수면선에는 얇은 밝은 라인 하나
- 프래그먼트 셰이더 절차적 **코스틱**. 흰색을 덧칠하는 대신 표면 고유색을 밝히는
  방식이라 밝은 바위에서도 날아가지 않고, 어두운 소일 위에서 또렷하게 보임.
  표면별 세기가 다르고(소일 > 바위 > 유목) 조명 밝기에 비례 — 달빛에서는 희미해짐
- 가산 합성 **광선(라이트레이)** 평면 7 장
- 우측 뒤 **에어스톤**에서 끊임없이 올라오는 기포 (사인 흔들림 + 가속 + 수면에서 팝,
  가끔 바닥에서 올라오는 잔기포), 수면 파문 링

## 기술 스택

- **Three.js 0.170.0** — import map 으로 jsdelivr 에서 고정 버전 로드
  (`three`, `three/addons/`)
- `OrbitControls`, `BufferGeometryUtils.mergeGeometries` (addons)
- 렌더링: `ACESFilmicToneMapping`, sRGB 출력, PBR(`MeshStandardMaterial`),
  `PCFSoftShadowMap` (1024)
- 커스텀 셰이더는 전부 `onBeforeCompile` 주입 (코스틱 / 수초 흔들림 / 물고기 유영 / 수면 파동)
  — 훅 함수를 공유해 프로그램 컴파일 수를 최소화
- 텍스처는 전부 `<canvas>` 로 그린 `CanvasTexture`
- `devicePixelRatio` 는 2로 상한, `InstancedMesh` 로 풀·이끼·기포 처리
- 삼각형 약 **46만**, 드로우콜 약 **295**, 셰이더 프로그램 26 개 (60fps 목표)
- 카메라가 창 비율에 맞춰 자동으로 거리를 잡아, 16:9 에서는 수조가 가로폭의 약 85 %를
  채우고 세로로 가운데 정렬됨. 세로로 긴 창에서는 잘리지 않게 뒤로 물러남
  (휠/핀치로 직접 확대하면 그 뒤로는 자동 조정하지 않음)

## 알려진 제약

- Three.js 를 CDN 에서 받으므로 **오프라인에서는 동작하지 않습니다.**
- 유리는 실제 굴절(`transmission`) 대신 가벼운 반투명 근사를 씁니다.
- 그림자 패스는 정점 셰이더 변형을 반영하지 않아, 흔들리는 수초·헤엄치는
  물고기의 그림자는 변형 전 형상 기준입니다.
- 물고기의 하드스케이프 회피는 실제 형상이 아니라 근사 구체 기준이라
  잔가지 끝을 아주 살짝 스칠 수 있습니다.
- 물고기·수초 그림자는 정점 변형 전 형상 기준이라 실제 실루엣과 미세하게 다릅니다.
- 저사양 내장 GPU 에서 프레임이 부족하면 `index.html` 상단
  `QUALITY` 블록의 `grass` / `mossWood` / `mossRock` / `bubbles` / `shadowMap`
  값을 낮추세요.
