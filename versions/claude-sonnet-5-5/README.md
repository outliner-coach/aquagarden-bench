# claude-sonnet-5-5 수족관

## 제작 방식
참고 이미지와 원프롬프트만 보고 단일 `index.html`을 작성. 모델/텍스처 파일 없음, 모든 형상·색은 코드로 절차적 생성(캔버스 그라데이션 텍스처 2종 제외 이미지 없음). three.js 0.160.0 (jsDelivr CDN, importmap, OrbitControls 포함).

## 구현 요약
- 물고기 5종 31마리: 붉은 베타 2, 네온 테트라 14, 노란 라스보라 8, 엔젤피시 3, 코리도라스 4(바닥 순항).
- 꼬리/지느러미: 몸통·꼬리·등/배지느러미·가슴지느러미를 별도 메시로 만들고 버텍스 셰이더(onBeforeCompile)에서 꼬리쪽 가중 사인파 + 지느러미 펄럭임 적용. 위상은 속도에 비례해 누적.
- 유영: 종별 군영(분리/정렬/결속)과 배회 목표, 벽·바닥·바위 회피.
- 수초: 줄기초 3종(연녹색 깃털형 / 붉은색) + 로제트 2종 + 잔디·키 큰 잎, 모두 InstancedMesh + 셰이더 흔들림.
- 하드스케이프: 노이즈 변위 바위 8개(이끼 정점색 + 이끼 인스턴스 최대 700), 층리 판석 쌓기, TubeGeometry 재귀 분기 유목, 단면이 보이는 소일/모래층, 자갈 260개.
- 기포: 에어스톤 3곳, 122개 인스턴스가 흔들리며 상승. 부유물 입자, 빛줄기 7개.
- 조명 컨트롤 6개 슬라이더(밝기, 주변광, 색온도, 조명 각도, 코스틱 강도, 안개 농도) + 프리셋 3개(낮/노을/달밤).
- 명언: 8개 분류(물고기·수초·바위·이끼·유목·기포·바닥·물) 총 24개. 클릭 시 하단 카드 표시(10초 후 사라짐).
- 렌더링: ACES 톤매핑, 그림자(PCFSoft 2048), FogExp2, 바닥/바위 코스틱 셰이더.

## 실제 수행한 검증 (Playwright MCP, 로컬 http.server 8792)
- 페이지 로드 후 콘솔 에러/경고 0건(최종 로드 기준. 초기에 favicon 404 1건이 있어 `data:` 아이콘으로 해소).
- `__stats()`로 물고기 31마리/5종 확인.
- 스크립트로 바위·수초 클릭 시 명언 카드 표시 확인, 화면 격자 클릭 시 fish/rock/moss/wood/plant/sand/bubble/water 8종 모두 히트 확인. 마우스 실클릭은 아님(내부 pick 함수 호출).
- 조명 밝기 슬라이더 값 변경 시 표시 값 갱신 확인(스크린샷으로 시각 변화 비교는 밝기 낮춤 상태를 직접 캡처하지 않음).
- 스크린샷으로 참고 이미지와 비교.

## 보정 내역
- 이끼 덩어리가 구슬처럼 커서 크기 축소·개수 증가·색 어둡게.
- 큰 바위의 이끼색 과포화 → 채도/비율 낮춤, 코스틱 강도 낮춤.
- 유목이 가늘어 굵기 증가.
- 초기 물고기 속도 NaN 가능성(종 파라미터 주입 전 초기화) 수정.

## 알려진 한계
- 식물 그림자는 흔들림을 반영하지 않음(그림자 깊이 패스는 정적).
- 지느러미는 반투명 평면이라 근접 시 단순함. 유목은 참고 이미지보다 가늘고 성김.
- 물고기-유목 가지 충돌 회피 없음(바위만 구 근사).
- 큰 바위에 코스틱이 마름모 무늬로 보이는 면이 있음.
- 성능 측정은 하지 않음(헤드리스 환경에서 동작만 확인).
